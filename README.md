# cplug_webui

Control Plugin's Automatic1111-based backend, designed to accelerate Control Plugin workflows.

This is a fork of [Stable Diffusion WebUI Forge — Neo](https://github.com/Haoming02/sd-webui-forge-classic/tree/neo) — see the upstream [README](https://github.com/Haoming02/sd-webui-forge-classic/blob/neo/README.md) for installation, features, and general documentation.

- [`CHANGES.md`](CHANGES.md) — fork-specific changelog. Upstream changes flow in via rebase and are not duplicated.
